# スクリーンショット置き場

README で参照する画面キャプチャを配置する。

- 命名は `<画面名>-<連番>.jpg`。連番は 1 枚しかない画面でも付ける（`review.jpg` ではなく `review-01.jpg`）。
- PC 表示だけは例外で `<画面名>-pc.png`（連番なし・横長のため PNG）。
- 実機（iPhone / Safari）で本番環境を撮影。README 側は `<img width="180">` で横並びに表示する
  （4 枚並べても GitHub の表示幅に収まるサイズ。5 枚以上になる節は表を 2 つに分ける）。
  PC 表示のみ表に入れず `width="700"` で単独配置する。
- 実在のメールアドレスなど個人情報が写り込んだものは置かない（デモ用アカウントで撮影する）。
- 管理者のログイン情報は README にも画像にも載せない（管理画面は撮影のみ）。
